# Evidence Index

[← README](../README.md)

Folder ini belum berisi hasil uji. Tambahkan bukti selama sprint; jangan memakai template kosong sebagai tanda kelulusan.

Gunakan path `evidence/D<day>/<run-id>/` untuk log, laporan, screenshot atau video singkat. Contoh run ID: `D6-TIFA-001`. Setiap run harus mencatat commit, version/artifact bila relevan, environment/config, robot_id, task_id, timestamp WIB, operator/owner, reviewer, expected/actual dan status.

| Run ID | Hari / tanggal WIB | Robot / environment | Criteria | Commit / artifact | Status | Laporan / bukti | Owner / reviewer |
| --- | --- | --- | --- | --- | --- | --- | --- |

Isi tabel setelah run nyata dilakukan. Buat laporan terpisah untuk TIFA dan NEVO. Bedakan bukti simulasi, bench, physical run dan clean install. Kegagalan dan retest memiliki run ID masing-masing serta tautan silang.

Simpan bukti besar sebagai release attachment atau penyimpanan yang diizinkan tim; catat tautan dan checksum agar dapat ditemukan. Gunakan data dan peta sintetis serta konfigurasi demo yang boleh dibagikan. GitHub memuat bukti yang cukup untuk review tanpa credential atau file mesin pribadi.
